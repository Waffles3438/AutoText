# AutoText

AutoText is an Ornithe 1.8.9 client mod built with OneConfig. Bind saved chat messages and commands to individual keys, then trigger them with one press.

- Messages are sent as normal chat text.
- Text beginning with `/` is sent as a command.
- Macros can be enabled or disabled independently.
- The mod does not restrict messages or commands based on the connected server.

Open AutoText from the OneConfig settings screen to add macros, edit their text, and assign keybinds.
